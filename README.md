# `latincymorph`

> *See release notes.*


A Python library to extract Latin syntax data from latincy's spaCy data.


Patrick Burns has created invaluable resources for nature-language processing of Latin and Greek texts with the Python `spaCy` package. The spaCy analyses include morphological indentifications for every lexical token.

`latincymorph` extracts morphological analyses of a Latin passage into a simple model that can used with generic Python tools including polars data frames.
